# SDSTL 频域诊断分步方案

更新日期：2026-10-15。当前阶段：阶段 1 的远程 20 样本 smoke、100 样本 full、同 100 样本离线 Edge 对照与训练索引配对审计已核对；真实加载器单批次检查已通过。阶段 2 的 baseline 在当前测试集复测为 331/1000，早层 20 样本探针已运行并分析；阶段 3 至 5 尚未开始。

阶段 1 的运行命令、输出和检查项见 [stage1.md](stage1.md)；开源参考审查见 [references.md](references.md)；真实数据分析结果统一索引在 [results/](results/README.md)。

本目录统一管理频域分析方案、后续实现及实验索引。目标是定位 RGB→Edge→DVS 流程中信息差异的来源，区分输入表征、事件预处理、网络传播和迁移训练的作用，再依据证据决定改进方向。

## 1. 已确认的约定

- **双 Sobel 是当前默认设计**：两个相同 Sobel 梯度幅值通道组成 Edge 输入。暂不使用 Canny，也不把双 Sobel 视为待修复错误。
- 双通道 Edge 提供重复的空间结构信息，不等价于 DVS 的正负极性；极性差异是研究对象。
- 先分析已有数据和模型，不在第一轮替换池化、添加频域损失或重训主模型。
- 实验在远程服务器运行。本地主要维护方案、代码和小型汇总，不能把本地检查称作远程实验验证。
- 按阶段实施；每阶段先报告观察、限制和下一步决策，避免一次性铺开全部实验。
- 编写各阶段代码前，先检索 GitHub 等开源实现，核对实际代码、论文定义、许可证和适用条件，再决定复用或自行实现。

## 2. 研究问题与判断边界

主问题：**双 Sobel 预训练获得的空间结构，能否在真实 DVS 上被激活，并穿过网络前两次下采样？**

进一步区分：

1. 输入域差异：RGB、双 Sobel、DVS 的空间频带、极性及时间结构有何不同？
2. 数据处理差异：事件分箱、缩放、归一化改变了哪些信息？
3. 网络传播：哪些变化发生在卷积、BN、LIF、池化及后续层？
4. 迁移作用：预训练初始化和微调如何改变模型对频率信息的利用？
5. 任务相关性：被削弱或增强的频率是否真正影响分类，而非仅反映噪声或发放率？

不预设“高频越多越好”。空间频率与时间频率分别定义；LIF 时间积分的低通性质不自动构成空间边缘衰减的证明。MaxPool 是非线性操作，DWC 的行为取决于学到的权重，不能给它们指定普适固定的高通响应。

## 4. 分步实施

### 阶段 0：核实实验条件与复用方案

**目标**：确定分析对象和测量定义，不改变训练行为。

工作：

- 核实远程代码版本、项目路径、Python 环境、现有依赖和可用计算资源。
- 列出现有 baseline、RGB→Edge 预训练、加载预训练权重的 DVS 微调、联合 Edge→DVS 训练的 checkpoint；缺少的项目标记缺失，不默认已完成。
- 为每个 checkpoint 记录模型类、训练入口、数据划分、T、图像尺寸、seed、注意力开关、损失配置、选择最佳模型的规则和实际加载的模块。
- 区分“预训练后只用 DVS 微调”和“源/目标双路联合训练”，不可合并为同一种迁移。
- 核实训练时的真实配置；当前源码不一定等同于旧 checkpoint 的生成版本。
- 检索开源频谱分析、SNN 中间特征采集、频带干预方法；优先原作者仓库及官方文档。记录 URL、文件/函数、commit、许可证、输入维度、归一化和时空聚合方式。
- 确定首批数据集和固定分析子集：优先选择路径合规、baseline 和预训练权重均可用的数据集；配对研究可另选具有可靠样本 ID 的数据。

产物：实验清单、参考实现清单、固定样本清单、指标定义。开源方案记录明确区分“发现候选”和“已审查可复用”。

完成条件：模型来源与数据访问路径明确；不匹配项已记录；能够说明每组比较只改变哪些因素。缺少某个权重不阻塞数据层分析。

### 阶段 1：输入数据与双 Sobel 桥梁

**目标**：先回答网络之前的差异。

观察对象：RGB/灰度参照、实际双 Sobel 输出、DVS 逐帧双极性数据；有原始事件时再比较分箱与缩放前后。不能仅凭处理后的 `.pt` 反推已丢失的信息。

首批指标：

- 原图、逐帧图、二维对数功率谱和径向功率谱。
- 原始能量、空间去均值后的低/中/高频能量及占比，空样本比例。
- 两通道相关性、活动像素比例、每帧/每极性事件计数或响应总量。
- DVS 两极性分别统计，并补充和通道、差通道；不将 RGB 通道与 DVS 极性通道机械对应。
- 归一化前后分别观察。对实际送入模型的标准化 RGB 计算 Sobel，同时保留原始像素域参照，避免改变预处理后误称复现。

配对规则：RGB 与其在线 Edge 可以逐实例比较；Edge 与 DVS 只有确认样本 ID 和几何关系后才做逐实例结构比较。仅同类的数据按类分布比较。

核查项：CEP-DVS 分箱采用 `T-1` 缩放后取整，检查末帧事件量及全序列分布；所有历史预处理疑点先记录，不在诊断时静默修正数据。

产物：数据频谱概览、类别级统计、代表性与异常样本、输入域差异说明。

完成条件：明确哪些差异来自极性、密度、空间尺度或预处理；不把功率谱接近等同于语义或相位对应。

### 阶段 2：单个模型中的层间传播

**目标**：定位变化发生在哪个运算前后，首轮重点是输入层和前两次池化。

采集位置：Conv 后、BN 后、LIF 放电前膜电位、输出脉冲、池化前后、下一层连续特征。必要时再拓展到完整主干。

实施要求：

- 首先选择一个现有 DVS baseline，固定同一批样本、eval 模式和前处理。
- 同时报告频谱、特征尺度和脉冲发放率；不能只看二值脉冲的宽频谱。
- 如需提取膜电位，保证采集前后模型 logits 一致，不改变 reset、BN 状态或原始 forward 的行为。
- 主模型多次复用同一个池化模块对象；采集记录必须区分调用次序和层位置，不能让后一次 hook 输出覆盖前一次。
- 不对 flatten 后的通道/特征索引做 FFT 并解释为空间频谱。末端 3×3 特征不用于精细频带结论。

产物：层位置×频带统计、池化前后对比、时间步变化、候选瓶颈列表。

完成条件：区分频率比例变化、幅度变化和发放率变化；不同分辨率的比较有明确坐标约定，不将比例差称为严格的信号传递增益。

### 阶段 3：迁移前后的频率利用

**目标**：检验双 Sobel 预训练改变了什么，以及变化是否保留到 DVS 微调后。

按实际可用权重选择比较组：随机初始化、DVS baseline、加载预训练后的初始化状态、DVS 微调后、联合 Edge→DVS 训练后。缺失组暂不补训。

两种比较分别开展：

- 固定同一模型，改变输入域，观察域适应差异。
- 固定同一批 DVS，改变模型状态，观察学习与迁移差异。

必须控制或标注：

- 预训练 T=2 与 baseline T=10 等差异：先保留各自原始设置，再单列统一评估 T 的诊断，不混为同一性能比较。
- 预训练模型 bottleneck 后有 LIF、baseline 没有；优先比较共同主干，末端按各自真实结构报告。
- Caltech 索引配对、CIFAR 类内配对、源/目标标签是否一致。联合训练器的源标签用于目标分类这一行为必须纳入核查。
- 无可靠实例对应时，不解释跨域逐样本 MSE/CKA 为结构保真；模型之间用同一 DVS 样本比较可以建立对应。
- 在保留 H/W 的特征上先分频带，再计算适用的相似度或分布统计；分析指标暂不加入训练损失。

产物：迁移比较报告，明确收益/退化出现在哪一层、哪个频段，以及仍存在的混杂因素。

完成条件：能够区分空间先验迁移、时间动态差异、结构不一致及配对问题；无法区分的情况明确标记为未解决。

### 阶段 4：验证频率与任务的关系

**目标**：检验频谱观察是否与分类有关。

按前几阶段证据选少量干预，不一次遍历全部组合：

- 输入或选定特征层的低通/高通/带阻抑制，扫描少量预先确定的强度。
- 时间打乱与时间平均重复，用于区分顺序、动态和静态累积结构。
- 保持事件总量的空间随机化对照，用于区分结构与稀疏噪声；仅在适用的原始计数表示中宣称保留事件数。
- 极性交换或合并，诊断双 Sobel 重复通道先验与真实极性之间的差异。

同时记录准确率、输出变化、能量变化、发放率和扰动大小。输入滤波可能产生负值或改变计数语义；明确标为诊断输入，不直接称为物理事件。截断、重标定会重新改变频谱，必须记录并检查。

产物：频带/时间/极性干预的性能曲线及结论边界。

完成条件：仅把结果表述为当前扰动下的敏感性证据；结合能量对照和层内干预，减少分布外扰动造成的误判。

### 阶段 5：依据证据设计改进实验

只有前几阶段提供明确依据后，才讨论代码改动与重新训练：

| 观察 | 优先考虑的方向 |
|---|---|
| 输入域在极性、密度或时序上差异突出 | 表征适配、预处理及迁移策略 |
| 前期下采样对任务相关结构影响明显 | 局部池化替换、下采样方式的受控对照 |
| 特定频带未有效迁移 | 分频带对齐，且先验证配对前提 |
| 频谱增强但分类无改善 | 噪声抑制、语义相关性和泛化 |
| 时间扰动影响明显但静态预训练收益有限 | 动态适配或时序约束 |

每次只改变一个主要因素，固定划分及模型选择规则，并以多个 seed 评估训练结论。直接在已训练模型中换池化仅属于诊断，不能替代重新训练后的公平比较。不得基于测试集反复挑选频带或架构。

## 5. 测量与结果规范

- 统一张量说明：SDSTL 通常为 `[N,T,C,H,W]`，MaxFormer 内部多为 `[T,N,C,H,W]`，不得直接照搬轴编号。
- 空间 FFT 使用明确的归一化；逐样本、逐帧、逐通道计算功率后聚合。时间累积图的频谱独立报告，不代替逐帧分析。
- 二维谱显示可取对数；能量指标在线性功率上计算。去除 DC 与不去除 DC 的结果分开保存。
- 频带边界在正式比较前确定并保存，采用频率坐标，不按图像亮度定义“高频”。处理矩形图、半径角区和不同分辨率时说明归一化规则。
- 时间频率默认使用 cycles/bin；仅在已知等间隔真实时间宽度时转为 Hz。样本时长不同、分箱数相同，不代表相同物理频率。短 T 只做粗粒度诊断。
- 样本量、类别分层、空帧、零能量、边界效应以及是否加窗均需记录；零能量占比不能用除零修补后掩盖。
- 报告样本/类别分布及不确定性，不能把同一样本的通道和时间步当作独立样本。单个 checkpoint 的置信区间不代表训练 seed 的不确定性。
- 开始实现后，用常数图、已知频率正弦、脉冲/噪声、零张量和静态重复序列验证指标定义；检查能量归一化和采集前后预测一致性。
- 完整实验前先小批量验证内存开销，采用在线累计或分批保存，避免缓存全部中间特征。
