## 同 100 个样本的空间频谱

各频带为逐样本、逐通道、去空间均值后的二维功率占比，再对样本取均值。三种输入都以 48×48 计算，但源 Edge 是静态图，DVS 是 10 帧双极性事件，不能把频带差称为模型的传递增益。

| 输入/通道 | 低频 % | 中频 % | 高频 % | 非零比例 % |
|---|---:|---:|---:|---:|
| 在线双 Sobel，两个相同通道 | 43.60 | 34.97 | 21.43 | 100.00* |
| 离线 Edge `.pt` 通道 0 | 41.98 | 36.16 | 21.86 | 原文件 99.45；加载后 100 |
| 离线 Edge `.pt` 通道 1 | 41.64 | 35.47 | 22.89 | 原文件 99.75；加载后 100 |
| 处理后 DVS 通道 0 | 20.92 | 29.61 | 49.47 | 10.63 |
| 处理后 DVS 通道 1 | 19.10 | 27.98 | 52.92 | 9.46 |

离线 Edge 的平均高频比例与在线双 Sobel 接近，但逐样本并不稳定：离线通道 0 减在线 Sobel 的差值平均 **+0.43** 个百分点、范围 **-17.77～+14.13**；通道 1 平均 **+1.46** 个百分点、范围 **-16.01～+17.11**。各自仅有 55/100、58/100 个样本差值为正。在线两通道相关系数为 1；离线两通道的样本平均相关系数约 **0.0077**（范围 -0.295～0.657）。因此平均频谱相近不代表相同通道结构或相同样本响应。

处理后 DVS 通道 0/1 比同编号离线 Edge 的高频比例分别高 **27.61/30.03** 个百分点，两组均为 100/100 样本同向；甚至逐样本 DVS 较低的那个通道仍高于离线 Edge 较高的那个通道。这里的“同编号”仅用于整理数据：离线 Edge 通道按当前预处理源码意图为 `|Gx|`、`|Gy|`，DVS 通道是负、正极性，没有一一对应语义。此次只读取保存的 Edge `.pt`，没有从 RGB 重建它们以确认产生 `.pt` 的历史源码版本。

`EdgeDatasetCEPDVS` 对离线 Edge 做 `(edge-0.5)/0.5`：本次加载后两个通道的最小值平均约 **-1**，而 DVS 帧是稀疏非负值。该仿射变换在先去空间均值的频带占比上不改变结果，却明显改变送入模型的数值分布。活动比例使用 `abs(x)>1e-12`，加载后 Edge 100% 活动与 Sobel 的 100% 非零都不能解释成真实事件密度。离线 Edge 的近乎全密集静态输入与 DVS 的稀疏动态输入，是比平均高频比例更明确的域差异。

## 阶段性判断

阶段 1 的输入链已经显示三件事：配对和默认 CSV 路径在当前版本下正确；在线双 Sobel 与迁移训练用的离线 Edge 虽有相近平均频带，却不是相同两通道表征；DVS 在空间频谱、极性、稀疏度和时间维度上与两种 Edge 都明显不同。此前 100 样本 `full` 还复现了第 10 时间箱近乎为空的问题。这些观察不能证明迁移有效或无效，也不能证明某个频段对分类有益。

下一步先盘点**实际可用的 baseline、预训练与迁移 checkpoint**，记录其训练命令、源码版本、数据路径、T、模型结构和载入权重范围。确认可比的 DVS baseline 后，再用同一固定样本进入阶段 2 的前两次下采样层间测量；当前不需要重训或覆盖预处理数据。
