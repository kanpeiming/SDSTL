  二、预训练 RGB→Edge 数据集(train_rgb2edge.py 用 RGB 图像预训练编码器)
每个数据集条目统一包含以下字段:
  - 入口调用  : baseline.py / train_rgb2edge.py 中的调用与 encode_type
  - 加载函数  : dataloader 中的 get_xxx 函数
  - 数据集类  : 实际读取文件的 Dataset 子类
  - 绝对路径  : 硬编码在源码中的路径
  - 目录结构  : 文件在磁盘上的组织形式
  - 单样本格式: 每个 .pt/.mat/.jpg 存储的张量形状与含义
  - 标签来源  : 标签如何获得
  - 划分方式  : train/test 划分
  - 源码位置  : 关键代码行号(便于复核)

================================================================================
四、关键差异提示
================================================================================
1. CIFAR10-DVS 与 CIFAR10-RGB 目录形式对称(均按类别子目录), 但内容不同:
   - DVS: (T,2,H,W) 事件张量;  RGB: (3,H,W) 图像张量。
2. N-Caltech101 DVS 的 .pt 存【元组 (data,target)】, data 原始 (C,H,W,T),
   需 permute 转为 (T,C,H,W); 其余 DVS 多为 (T,2,H,W) 或元组。
3. CEP-DVS 的标签统一来自 pathFile.csv(不靠目录/不靠 .pt 第二元素),
   DVS 与 RGB 文件名同号(01891)一一对应, 便于配对。
4. CEP-DVS baseline 优先读预处理 .pt (dvs_processed), 不存在才回退原始 .mat;
   预处理 .pt 内第二个元素被丢弃, label 实际取自 csv。
5. 多处 .pt 加载使用 weights_only=True 以消除 FutureWarning
   (DVS/RGB 纯张量或元组场景均安全; 仅含自定义对象的 checkpoint 不加)。
