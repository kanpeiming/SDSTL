## 一、训练流程总览

```
┌─────────────────────────────────────────────────────────────────┐
│  阶段 1：预训练（RGB → Edge）                                    │
│  产出：rgb_edge_pretrained_best.pth                              │
│                                                                  │
│  train_rgb2edge.py   合并版（含 Caltech101/CEP-DVS/CIFAR10/MNIST）│
│    --use_trt 可选 TRT Loss                                       │
│    --epochs 兼容（等价 --epoch）                                 │
└─────────────────────────────────────────────────────────────────┘
                            │
                            │  预训练权重
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│  阶段 2：迁移学习（Edge/RGB → DVS）                              │
│                                                                  │
│  train_edge2dvs.py   合并版                                       │
│    --source_mode edge (默认)  Edge(2ch)->DVS  3 个数据集         │
│    --source_mode rgb          RGB(3ch)->DVS   2 个数据集         │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  阶段 3：基线对照（直接在 DVS 上训练 SNN）                       │
│                                                                  │
│  baseline.py   合并版（4 个数据集）                               │
│    --val_strategy none (默认)       不用验证集，基于 train_acc    │
│    --val_strategy test_as_val       用测试集当验证集，基于 val_acc│
│    --use_event_attention            事件注意力                   │
│    --load_features/bottleneck/...   选择性加载预训练模块         │
└─────────────────────────────────────────────────────────────────┘
```

**模型与损失函数统一**：所有脚本都用 `VGGSNN`（或 `VGGSNNwoAP`）+ `TET_loss`（或 `TRT_loss`）。

## 二、3 个主入口脚本

### 1. `baseline.py` — 基线训练入口（合并版）

**合并自**：`baseline.py` + `train_caltech101_baseline.py`

**定位**：直接在 DVS 事件数据上训练 SNN，作为迁移学习方法的性能对照基准。

**支持数据集**：CIFAR10-DVS、N-MNIST、N-Caltech101、CEP-DVS（4 个）

**核心参数**：

| 参数 | 默认 | 说明 |
|------|------|------|
| `--data_set` | CIFAR10 | 数据集类型 |
| `--val_strategy` | none | `none`=不用验证集(基于train_acc) / `test_as_val`=用测试集当验证集(基于val_acc) |
| `--caltech101_dvs_path` | None | Caltech101 .pt/.bin 路径；不提供则用 get_n_caltech101 (.mat) |
| `--use_event_attention` | False | 事件中间帧引导注意力 |
| `--event_attention_reduction` | 8 | 事件注意力通道压缩比 |
| `--load_features` | False | 选择性加载 features 模块 |
| `--load_bottleneck` | False | 选择性加载 bottleneck 模块 |
| `--load_classifier` | False | 选择性加载 classifier 模块 |
| `--load_dvs_input` | False | 选择性加载 dvs_input 模块 |
| `--use_eventrpg` | False | EventRPG 数据增强 |
| `--pretrained_path` | None | 预训练权重路径 |

**保存路径**：
- TensorBoard：`/home/user/kpm/kpm/results/SDSTL/baseline/log_dir_{data_set}/{log_name}/`
- 模型权重：`/home/user/kpm/kpm/results/SDSTL/baseline/checkpoints_{data_set}/{log_name}.pth`

**启动命令**：
```bash
# 原始 baseline.py 用法（不用验证集）
python baseline.py --data_set CIFAR10

# 原 train_caltech101_baseline.py 用法（用测试集当验证集）
python baseline.py --data_set Caltech101 --val_strategy test_as_val \
    --caltech101_dvs_path /path/to/caltech101_dvs \
    --use_event_attention --load_features --load_bottleneck --load_classifier
```

### 2. `train_rgb2edge.py` — RGB→Edge 预训练入口（合并版）

**合并自**：`train_rgb2edge.py` + `train.py`

**定位**：使用 RGB 图像作为源域、RGB 边缘信息作为目标域，训练能提取 DVS 类似特征的网络，产出预训练权重。

**支持数据集**：Caltech101、CEP-DVS、CIFAR10、MNIST（4 个）

**核心参数**：

| 参数 | 默认 | 说明 |
|------|------|------|
| `--data_set` | Caltech101 | 数据集（Caltech101/CEP-DVS/CIFAR10/MNIST） |
| `--epoch` / `--epochs` | 30 | 训练轮数（两个参数名都支持，--epochs 优先） |
| `--use_trt` | False | 使用 TRT (Temporal Regularization Training) Loss |
| `--trt_decay` | 0.5 | TRT decay δ |
| `--trt_lambda` | 1e-5 | TRT 正则化系数 λ |
| `--trt_epsilon` | 1e-5 | TRT epsilon ε |
| `--trt_eta` | 0.05 | TRT eta η (MSE loss weight) |
| `--rgb_to_gray` | False | RGB 转灰度后提取边缘 |
| `--use_woap` | False | 使用 VGGSNNwoAP（无 AvgPool） |

**特性**：
- Sobel + Canny 双边缘提取器生成 2 通道边缘图
- Caltech101：手动 90/10 划分防泄露
- CIFAR10/MNIST：只用训练集，预训练阶段不测试（原 train.py 行为）
- 优化器分层学习率：输入层 lr×10

**保存路径**：
- 预训练权重：`/home/user/kpm/kpm/results/SDSTL/pretrain/checkpoints/{data_set}_EdgePretrain_{num_classes}_{log_name}/rgb_edge_pretrained_best.pth`

**启动命令**：
```bash
# 原 train_rgb2edge.py 用法
python train_rgb2edge.py --data_set Caltech101 --epoch 50 --lr 0.001
python train_rgb2edge.py --data_set CEP-DVS --epoch 50

# 原 train.py 用法（CIFAR10/MNIST + TRT Loss）
python train_rgb2edge.py --data_set CIFAR10 --epochs 50 --use_trt --trt_lambda 1e-5
python train_rgb2edge.py --data_set MNIST --epochs 50
```

### 3. `train_edge2dvs.py` — Edge/RGB→DVS 迁移学习入口（合并版）

**合并自**：`train_edge2dvs.py` + `train_rgb2dvs.py` + `tl.py`

**定位**：加载 RGB→Edge 预训练权重，使用 Edge/RGB 数据作为源域、DVS 数据作为目标域进行迁移学习。

**支持数据集**：Caltech101、CIFAR10、CEP-DVS（source_mode=rgb 不支持 CEP-DVS）

**核心参数**：

| 参数 | 默认 | 说明 |
|------|------|------|
| `--source_mode` | edge | `edge`=Edge(2ch)源域 / `rgb`=RGB(3ch)源域 |
| `--data_set` | Caltech101 | 数据集 |
| `--edge_root` | 自动 | Edge 数据根目录 (source_mode=edge) |
| `--dvs_root` | 自动 | DVS 数据根目录 (source_mode=edge) |
| `--RGB_sample_ratio` | 1.0 | RGB 训练集比例 (source_mode=rgb) |
| `--edge_sample_ratio` | 1.0 | Edge 训练集比例 (source_mode=edge) |
| `--dvs_sample_ratio` | 1.0 | DVS 训练集比例 |
| `--split_ratio` | 0.9 | Train/test 划分比例 (source_mode=rgb) |
| `--use_event_attention` | False | 事件注意力 |
| `--pretrained_path` | 自动 | RGB→Edge 预训练权重路径 |

**特性**：
- source_mode=edge：域差异最小（2ch→2ch），支持 3 个数据集
- source_mode=rgb：RGB 直接迁移（3ch→2ch），Caltech101 自动移除 Faces 类
- 输出 test_acc1（Top-1）和 test_acc5（Top-5）

**保存路径**：
- 模型权重：`/home/user/kpm/kpm/results/SDSTL/transfer/checkpoints/{source_tag}2DVS_{data_set}_{num_classes}_{log_name}/best_model.pth`
- TensorBoard：`/home/user/kpm/kpm/results/SDSTL/transfer/log_dir/{source_tag}2DVS_{data_set}_{num_classes}/{log_name}/`

**启动命令**：
```bash
# 原 train_edge2dvs.py 用法（Edge 源域，默认）
python train_edge2dvs.py --source_mode edge --data_set Caltech101 --pretrained_path /path/to/pretrained.pth --epoch 100
python train_edge2dvs.py --source_mode edge --data_set CEP-DVS --epoch 100

# 原 train_rgb2dvs.py 用法（RGB 源域）
python train_edge2dvs.py --source_mode rgb --data_set Caltech101 --pretrained_path /path/to/pretrained.pth --epoch 100
python train_edge2dvs.py --source_mode rgb --data_set CIFAR10 --epoch 100
```

## 五、典型训练流程

### 流程 A：完整迁移学习（Edge 源域，推荐）

```bash
# 1. 预训练 RGB→Edge
python train_rgb2edge.py --data_set Caltech101 --epoch 50

# 2. Edge→DVS 迁移学习
python train_edge2dvs.py --source_mode edge --data_set Caltech101 \
    --pretrained_path /path/to/rgb_edge_pretrained_best.pth --epoch 100

# 3. 基线对照
python baseline.py --data_set Caltech101
```

### 流程 B：RGB 直接迁移

```bash
# 1. 预训练 RGB→Edge（可选但推荐）
python train_rgb2edge.py --data_set Caltech101 --epoch 50

# 2. RGB→DVS 迁移学习
python train_edge2dvs.py --source_mode rgb --data_set Caltech101 \
    --pretrained_path /path/to/rgb_edge_pretrained_best.pth --epoch 100
```

### 流程 C：CIFAR10 基线 + TRT 预训练

```bash
# 基线
python baseline.py --data_set CIFAR10

# TRT Loss 预训练
python train_rgb2edge.py --data_set CIFAR10 --use_trt --trt_lambda 1e-5 --epochs 50
```

## 六、公共组件

- **模型**：`models/snn_models/VGG.py` → `VGGSNN` / `VGGSNNwoAP`
- **训练器**：
  - `tl_utils/trainer.py` → `Trainer` / `BaselineTrainer` / `TLTrainer`
  - `pretrain/edge2dvs_trainer.py` → `AlignmentTLTrainer_Edge2DVS`
  - `pretrain/pretrainer.py` → `AlignmentTLTrainer_Edge_1`
- **损失函数**：`tl_utils/loss_function.py` → `TET_loss` / `TRT_loss`
- **数据加载**：`dataloader/` → cifar、mnist、caltech101、cepdvs、eventrpg_augment
- **边缘提取**：`pretrain/Edge.py` → `SobelEdgeExtractionModule` / `CannyEdgeDetectionModule` / `RGB2GrayscaleModule`
