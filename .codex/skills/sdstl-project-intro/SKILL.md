# SDSTL Project Intro

Use this skill when the user asks for a quick understanding of the SDSTL codebase, asks what the project does, resumes work in `C:\coding\SDSTL`, or wants an onboarding style summary before editing or running experiments.

## Core Understanding

SDSTL is an event camera and spiking neural network transfer learning project. Its main idea is structural decoupling: use RGB image edges as an intermediate bridge so knowledge learned from RGB images can transfer more smoothly into DVS event data.

The conceptual pipeline is:

```text
RGB image
  -> Sobel/Canny edge representation
  -> RGB-to-Edge pretraining
  -> Edge/RGB-to-DVS transfer learning
  -> DVS SNN classification
```

The main model family is `VGGSNN` with temporal SNN training. The important loss functions include `TET_loss`, optional `TRT_loss`, and transfer alignment losses such as CKA/TCKA, MMD, and MSE.

## Main Entrypoints

- `baseline.py`: trains an SNN directly on DVS data. This is the baseline for comparison against transfer learning.
- `train_rgb2edge.py`: stage 1 pretraining. It trains from RGB images toward edge style supervision generated by Sobel/Canny modules.
- `train_edge2dvs.py`: stage 2 transfer learning. It transfers from Edge or RGB source data to DVS target data.

The project documentation says older overlapping scripts were merged into these three main entrypoints.

## Current Innovation Logic

The project can be explained as three connected contributions:

1. Structural decoupling transfer: RGB to Edge to DVS reduces the RGB and event domain gap.
2. Sample alignment plus event attention: aligned or synthetic DVS can make middle event frames better attention priors.
3. MaxPool high frequency compensation: SNN/LIF dynamics are low pass, while edges are high frequency, so replacing AvgPool with MaxPool may preserve useful edge detail.

These ideas support each other: alignment gives corresponding high frequency structure, MaxPool keeps that structure, and event attention uses a better mid frame prior.
